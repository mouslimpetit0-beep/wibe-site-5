# ISLAM WEB - موقع تصميم وبرمجة المتاجر الإلكترونية

موقع ثابت (HTML واحد) جاهز للنشر على GitHub Pages.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (New repository) على GitHub، مثلاً باسم `my-site`.
2. اضغط Add file ثم Upload files، وارفع الملفين `index.html` و`.nojekyll`.
3. اضغط Commit changes.
4. من Settings ثم Pages: اختر Deploy from a branch، والفرع main والمجلد / (root)، ثم Save.
5. بعد دقيقة يعمل الموقع على: https://USERNAME.github.io/my-site/

## لوحة التحكم
ثلاث ضغطات سريعة على شعار الموقع أعلى الصفحة، ثم الرقم السري (غيّره من الإعدادات).

## ملاحظات
- البيانات (الطلبات والصور والنصوص) تُحفظ في متصفح كل زائر، لا على GitHub.
- المستودع العام يعني أن الكود ظاهر للجميع، بما فيه الرقم السري الافتراضي.
